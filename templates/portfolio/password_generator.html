Why strong passwords matter

Short or reused passwords are easy targets when a website leaks a password database. Attackers can try huge numbers of guesses offline, so every extra character and every bit of randomness makes a big difference.

Use unique passwords

Use a different password for every important account. If one site is breached, the same password should not unlock your email, banking, cloud, or admin accounts.

Always combine with MFA

Pair strong passwords with multi-factor authentication, especially for email, Microsoft/Google/Apple accounts, banking, password managers, hosting, and social media. Prefer an authenticator app, passkey, or hardware security key over SMS when possible.

Use a password manager

A password manager helps you keep long, random, unique passwords without memorising them. Memorise only your master password or passphrase, and protect that account with MFA.

Estimated cracking time
